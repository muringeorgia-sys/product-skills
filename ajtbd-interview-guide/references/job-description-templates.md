# Шаблоны описания работы

Используй после интервью (или как заготовку в конце гайда) — по одному
шаблону на каждую подробно прокопанную работу. Заполняй только тем, что
респондент реально сказал; поле, на которое не спросили или не ответили,
помечай как неизвестное, а не додумывай.

**Детальный шаблон** — для работы, которую прокапывали через основной
30-минутный блок (`questions-frequent-job.md` / `questions-sequential-job.md`).
**Короткий шаблон** — для работ, которые изучили бегло: предыдущие/
следующие работы или работы ниже уровнем.

- **когда** я в контексте, плюс психологические особенности, прошлый

- **хочу** получить ожидаемый результат
- **чтобы** получить ожидаемый результат работы выше уровнем и
  чувствовать себя по-другому в контексте выполнения работы выше уровнем

- **Важность выполнения работы:** — из блока [важность работы]
- **Частота выполнения работы:** — из блока [частотность работы], только
  для частотных работ
- **Решение, которое клиент нанял на эту работу:** решение
  - **Удовлетворённость решением:** X/10 — из блока [удовлетворённость
    решением]
  - **Ценность:** — из блока [ценность]
  - **Aha-moment:** — из блока [aha-moment]
  - **Стоимость + соответствие цены ценности:** $$$, X/10 — из блока
    [стоимость + соответствие цены и ценности]
  - **Проблемы с решением:** — список из блока [проблемы], если они есть
  - **Барьеры к решению:** — список из блока [барьеры к решению]
- **Низкоуровневые работы + результат:** список низкоуровневых работ и
  решений, если блок работ ниже уровнем прокапывали
