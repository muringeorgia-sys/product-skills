## Живая Google Таблица

Вынесено из SKILL.md 21.10.2026 без изменений текста.

Пользователь загружает xlsx в Google Таблицы и правит дальше там: меняет галочки, удаляет строки, дополняет аудитории. Просьбы «актуализируй пуши», «пересмотри пуши», «обновил аудитории» относятся к этой таблице. Ссылку даёт пользователь; для октября 2026 она записана в памяти `mashina-push-audiences`.

Работа идёт через Chrome пользователя (расширение Claude in Chrome), вкладка на самой таблице.

**Чтение.** `fetch('/spreadsheets/d/<id>/gviz/tq?tqx=out:csv&headers=0&sheet=<имя листа>')` из вкладки таблицы. Заголовки колонок-галочек gviz отдаёт пустыми - порядок каналов сверяй скриншотом. Галочки приходят как `TRUE`/`FALSE`, «Пуш Mashina» - последняя колонка каналов. Перед любыми правками сохрани снимок листов в `window`, чтобы потом сверить.

**Пересборка пушей.** Прочитай «Фичи» и «Аудитории пушей» заново - пользователь мог их изменить. Собери календарь по шагу 4 и покажи в чате таблицу того, что поменял.

**Запись.** Выдели левую верхнюю ячейку через поле названия (Name Box), затем вставь TSV событием вставки:

```js
if (!location.href.includes('gid=<gid нужного листа>')) throw new Error('wrong sheet');
const dt = new DataTransfer();
dt.setData('text/plain', rows.map(r => r.join('\t')).join('\n'));
document.activeElement.dispatchEvent(new ClipboardEvent('paste', { clipboardData: dt, bubbles: true, cancelable: true }));
```

- Проверка `gid` обязательна: клик по ярлыку листа по координатам однажды промахнулся, и вставка ушла в «Фичи». Если так случилось - сразу `Ctrl+Z`, затем сверь лист со снимком и честно скажи об этом пользователю.
- Даты вставляй полными (`02.10.2026`): ячейки сохраняют формат `дд.мм`, а короткое «02.10» превращается в число.
- Колонку «Отправляем» и номера строк не трогай - вставляй только B:F.
- После вставки перечитай оба листа через gviz: «Пуши Mashina» содержит новое, «Фичи» совпадает со снимком.

**Выпадающий список аудиторий.** Правило проверки на E-колонке ссылается на диапазон листа «Аудитории пушей». Когда пользователь добавляет аудитории, диапазон может их не захватить - у ячеек появляется красный уголок «Введите значение в указанном диапазоне». Лечится в Данные → Настроить проверку данных: диапазон `='Аудитории пушей'!$A$5:$A$30` (с запасом).

После изменения списка аудиторий обнови память `mashina-push-audiences`.
