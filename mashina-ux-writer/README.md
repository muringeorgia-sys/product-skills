# mashina-ux-writer — агент «UX-writer Mashina.kg»

Получает PRD от Product Owner и прописывает внутри него тексты интерфейса: приложение «Текст» по экранам и состояниям, дословные цитаты в разделах 3 и 6, глоссарий. Создан 19.10.2026.

## Как запустить

| Где | Как |
|---|---|
| Claude Code, чат с PM | `/mashina-ux-writer <путь к PRD>` или «пропиши тексты в PRD …» |
| Из другого агента | Агент `mashina-ux-writer` (`~/.claude/agents/mashina-ux-writer.md`) |
| Другая модель | Системный промпт = `lore.md` + `SKILL.md` + справочники |

## Состав

| Путь | Что это |
|---|---|
| `SKILL.md` | Порядок: разбор PRD → термины → тексты → запись в PRD → проверка → ответ |
| `lore.md` | Роль: опыт, рынок КР, продукт, знания на 10.2026, голос, форматы, границы |
| `references/patterns.md` | Шаблоны текстов по элементам, лимиты, склонения |
| `references/review-checklist.md` | Самопроверка |
| `mashina-designer/references/company.md`, `site-ui.md` | Общие с дизайнером: компания, голос бренда, текущий сайт. Не копируются |
