# Шаблоны текстов по элементам

Примеры — образец формы. Цены, сроки и названия бери из PRD.

## Склонение подстановок

Для каждой подстановки с числом — три формы:

| Число | Форма |
|---|---|
| 1, 21, 31… | объявление |
| 2–4, 22–24… | объявления |
| 0, 5–20, 25–30… | объявлений |

В таблице приложения пиши так: «Показать N объявление / объявления / объявлений».
