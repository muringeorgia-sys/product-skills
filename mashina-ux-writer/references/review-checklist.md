# Самопроверка перед сдачей

## Полнота
- [ ] У каждого экрана из PRD есть таблица в приложении «Текст».
- [ ] Описаны все применимые состояния: загрузка, пусто, ошибки, гость, роль, успех, недоступно.
- [ ] У каждого поля — подпись, у каждой ошибки — способ исправить.
- [ ] У каждой иконки без подписи — текст для скринридера.
- [ ] У каждой строки — лимит знаков.

## Точность
- [ ] Цены, сроки, лимиты, названия услуг — из PRD, без своих цифр.
- [ ] Нет обещаний и эффектов, которых нет в PRD.
- [ ] Финансовые суммы с «ориентировочно», если не окончательные.
- [ ] Юридический текст из PRD или помечен «согласовать с юристом».

## Язык и голос
- [ ] «Вы» со строчной. Заголовки без точки.
- [ ] Кнопки — глагол и результат, нет «Далее», «ОК».
- [ ] Нет канцелярита, капса, «!!!», стыжения при отказе, ложной срочности.
- [ ] Один смысл — одно слово во всём PRD. Термины совпадают с сайтом.
- [ ] Чужие тексты бенчмарка не скопированы.

## Форматы
- [ ] `N ⃀` после числа, неразрывный пробел в числах, даты `дд.мм.гггг`.
- [ ] У подстановок с числом — три формы склонения.

## Согласованность PRD
- [ ] Тексты в кавычках в разделах 3 и 6 совпадают с приложением дословно.
- [ ] Кроме приложения и цитат ничего не изменено.
- [ ] Вопросов в PRD нет, они в чате.
