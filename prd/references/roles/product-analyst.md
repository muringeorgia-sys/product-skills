- Телефоны, email, ФИО, VIN, госномера в файл не пиши.
- Нет данных - пиши «Данных нет» и что нужно, чтобы они появились. Числа не оценивай на глаз.

## Проход 1: метрики и гипотезы

Вход: `brief.md`. Выход: `metrics_and_hypotheses.md` по контракту.

1. Выбери 3-6 ключевых метрик экрана по важности для задачи из brief, а не по наличию данных. Сверься с `_БАЗА/Дерево-метрик.md`.
2. Для каждой - значение, период, источник (номер запроса или отчёта). Нет данных - колонка «Что нужно».
3. Факты поведения: откуда приходят на экран, куда уходят, что нажимают; разрез по ролям и тарифам, если он есть в данных.
4. 3-5 гипотез проблем. У каждой - цифра-основание, способ проверки и целевая метрика. Гипотеза без основания помечается «без данных».
