# Маршрутизация: кто на какой модели и как запускать

Цель - беречь лимит подписки Claude, в первую очередь Opus. Бесплатным моделям OpenCode - только публичные данные: публичные страницы Mashina.kg и конкурентов. Метрики, выручка, Jira, Confluence, brief и PRD - только Claude и Codex.

## Роли

| Роль | Как запускается | Модель · уровень |
|---|---|---|
| Orchestrator | Основной тред, шапка этого скилла | Claude Sonnet 5.5 · low |
| Site Researcher, все страницы | Субагент `prd-site-researcher`, по экземпляру на сайт | Sonnet 5.5 · medium |
| Product Analyst | Субагент `prd-product-analyst` | Sonnet 5.5 · medium |
| Core PM | Субагент `prd-core-pm` | Opus 5.5 · high |
| Core PM в Lite | Субагент `prd-core-pm-lite` | Sonnet 5.5 · high |
| UX Writer | Субагент `prd-ux-writer` | Sonnet 5.5 · medium |
| Product Designer | Субагент `prd-product-designer` | Sonnet 5.5 · medium |
| PRD Reviewer | Скрипт codex-companion | `gpt-6.1-sol` · high в Full, medium в Lite |
| Финальная чистка | Субагент `prd-cleanup` | Haiku 4.5 · low |
| Publisher | Субагент `prd-publisher` | Sonnet 5.5 · low (на Haiku 2026-10-14 не справился) |

Модель и уровень субагента заданы в шапке его файла в `~/.claude/agents/`. При вызове их не переопределяй.

## Решение от 2026-10-13

Сайты в Full снимает субагент Claude `prd-site-researcher`. Бесплатные модели OpenCode и Codex как исследователи не используются: на тесте бесплатная модель упала через 85 минут без отчёта, а Codex занял почти всё 5-часовое окно тарифа Plus. Codex остаётся только ревьюером. Раздел «Дочерний тред bb» ниже - справка на случай, если пользователь прямо попросит запустить внешний тред.

## Дочерний тред bb

Запуск треда - только после подтверждения состава агентов в волне 0. Проект не git-репозиторий, поэтому тред создаётся в текущем окружении.

```bash
bb thread spawn --project "$BB_PROJECT_ID" --environment "$BB_ENVIRONMENT_ID" \
  --provider acp-opencode --model opencode/mimo-v2.6-flash-free \
  --parent-self --title "PRD research: <сайт>" --prompt-file "<файл задания>" --json
# Codex: --provider codex --model gpt-6.1-sol --reasoning-level medium
bb thread wait <id> --timeout 30m
bb thread context <id> --json      # usedTokens - в run_log.md
```

- До первого запуска сделай один вызов bb-browser сам (список вкладок): при одновременном старте тредов демон браузера иначе не поднимается.
- Ожидание запускай в фоне; результат треда придёт и сообщением `[bb system] ... completed`.
- Бесплатная модель может работать 15-20 минут без видимого прогресса - это не зависание.
- После завершения проверь список вкладок bb-browser и закрой вкладки, оставленные тредами прогона.

## Субагенты Claude

Вызов через Agent с `subagent_type` из таблицы. Параллельные агенты одной волны - в одном сообщении. Для следующего прохода того же агента используй SendMessage к уже запущенному: контекст не перечитывается. Токены бери из отчёта о завершении агента.

Если типа агента нет в списке доступных (файл создан после старта сессии) - вызови `general-purpose` с параметром `model` из таблицы и первой строкой задания: «Прочитай и выполняй `~/.claude/skills/prd/references/roles/<роль>.md`».

## Ревьюер

Скрипт: самая новая версия `~/.claude/plugins/cache/openai-codex/codex/*/scripts/codex-companion.mjs`. Запуск из корня проекта, без `--write`, таймаут 600000 мс:

```bash
node "<скрипт>" task --model gpt-6.1-sol --effort <high для Full, medium для Lite> --prompt-file "<файл промпта>"
```

Промпт и правила - `review.md`.

## Запасные варианты

| Сбой | Что делать |
|---|---|
| Отчёт исследователя не прошёл проверку | Один повтор тем же агентом с указанием, чего не хватило |
| Codex недоступен или лимит исчерпан | Ревью - `general-purpose` с `model: sonnet` и промптом из `review.md` |
| Publisher ошибся при записи | Проверить состояние на сервере, затем повтор через `general-purpose` с `model: sonnet` |
| Субагент или тред не ответил | Один повтор той же задачи; затем статус «частично» и запись в run_log.md |

Не выполняй работу специалиста сам от его имени: оркестратор на слабой модели и без контекста роли.

## Замеры

До и после прогона запиши в `run_log.md` вывод `bb settings usage`: проценты 5-часового и недельного окна Claude и Codex. По каждому агенту - токены и время.

## Провайдер без субагентов

Codex и другие провайдеры без инструмента Agent работают только в режиме Lite: один агент последовательно читает `roles/core-pm.md` (раздел «Режим Lite») и нужные references. Дочерние треды не запускает.

## Уроки прогона на главной странице (2026-10-09)

- **Несколько тредов.** `bb thread wait` принимает один id. Жди параллельно: по одной фоновой команде на тред либо по сообщениям `[bb system] ... completed`. Между уведомлениями ход оркестратора заканчивается - это нормально.
- **Лимит на бесплатную модель - 20 минут.** В задании требуй записать черновик файла после первого экрана и дополнять его. Через 20 минут файла нет или тред в ошибке - останови тред (`bb thread stop <id>`) и запусти запасной вариант. На полной задаче по главной бесплатная модель проработала 85 минут и упала без файла.
- **CAPTCHA.** Если исследователь вернул блокер CAPTCHA, другой моделью не повторяй: это только увеличит число автоматических заходов. Открой страницу во вкладке bb-browser, попроси пользователя пройти CAPTCHA, затем повтори задание в этой же вкладке (id вкладки - в задании, новую не открывать, в конце не закрывать).
- **Авторизованный браузер.** Если пользователь вошёл в аккаунт в управляемом браузере, страницы уже не публичные: бесплатной модели их не давай, запускай Codex.
- **Рестарт демона bb** обрывает дочерние треды. После него проверь, есть ли файл результата; нет - запусти задание заново.
- **Codex на тарифе Plus дорог как исследователь:** два треда исследования и ревью заняли большую часть 5-часового окна. Перед запуском посмотри `bb settings usage`; если окно Codex занято больше чем на 50%, предупреди пользователя.
- **Список файлов.** В задании агенту перечисляй входные файлы абсолютными путями по одному в строке; не пиши «файлы в папке материалов».
