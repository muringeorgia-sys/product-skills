## 2. Redash

- Адрес: `http://92.204.189.31:8082`. Список дашбордов Mashina: `/dashboards?order=-created_at&q=mashina`.
- **API напрямую** (ключ в переменной Windows `REDASH_API_KEY`, уровень User; ключ не печатаешь, в файлы не пишешь):
  ```
  powershell.exe -NoProfile -Command '$k=[Environment]::GetEnvironmentVariable("REDASH_API_KEY","User"); Invoke-RestMethod -Uri "http://92.204.189.31:8082/api/queries/326" -Headers @{Authorization="Key $k"}'
  ```
  - Через bash + curl ключ не вытаскиваешь — только PowerShell.
  - Кириллица в выводе PowerShell ломается: пиши результат в файл `tmp/` через `ConvertTo-Json | Out-File -Encoding utf8` и читай Read.
- Запуск запроса: `POST /api/queries/<id>/results` с `{parameters, max_age: 0}` → job → `GET /api/jobs/<id>` (status 3 = готово) → `GET /api/query_results/<result_id>`.
- Ad-hoc SELECT без сохранения: `POST /api/query_results` с `{data_source_id, query, max_age: 0, parameters: {}}`. Только SELECT. С API-ключом даёт 500 (20.10) — делай через `fetch` с вкладки Redash в Comet.
- Запас без API: `fetch` с вкладки Redash в Comet (та же схема).

### Правила

- Только дашборды, созданные **с 12.05.2026**. Запрос, который живёт только на старом дашборде, не используешь.
- Активные объявления — **только дашборд 77**. Счётчик на главной сайта и запросы 268/271 не используешь.
- Выручка — по правилу `_БАЗА/Правило_Расчёт-выручки-как-в-финотчёте.md`. `balance` и `osago` — не оплаты.
- Комиссии банка за кредит в транзакциях нет — только в финотчёте.

## 5. Adjust

- **API напрямую** (с 20.10): Report Service API, токен в переменной Windows `ADJUST_API_TOKEN` (User). Токен не печатаешь, в файлы не пишешь.
  ```
  powershell -NoProfile -File ~/.claude/skills/mashina-analyst/scripts/adjust_report.ps1 -period "2026-10-12:2026-10-18" -dimensions "day,os_name" -metrics "installs,sessions,daus" -out tmp/analyst_<дата>/adjust.json
  ```
  - `dimensions`: `app`, `day`, `week`, `month`, `os_name`, `country_code`, `network`, `campaign`, `adgroup`, `creative`.
  - `metrics`: `installs`, `reattributions`, `sessions`, `daus`, `waus`, `maus`, `clicks`, `impressions`, `cost`, события и ретеншн — список в документации Adjust Report Service API. Неизвестное имя → ошибка 400, смотри текст ошибки.
  - Фильтры через `-extra`: `&os_name__in=ios`, `&country_code__in=kg`.
  - `daus` за период — среднее в день, не сумма.
  - Токен отозван или неверен (401/403) — скажи PO, ввод нового: `scripts/set_adjust_token.ps1` (скрытое окно).
- Приложение в отчёте: `Mashina.kg` (iOS и Android).
- Datascape (браузер) — только если нужен вид готового дашборда: `https://suite.adjust.com/datascape/custom-dashboard-list`.
- Даёт: установки, переустановки, сессии, атрибуция по сетям и кампаниям, ретеншн D1/D7/D30, события приложения.
- Установки ≠ пользователи GA4. Сравниваешь тренды.
- iOS: часть установок через SKAN / AdAttributionKit — данные приходят с задержкой до 3 дней, последние дни неполные.
- Ничего не создаёшь и не меняешь: дашборды, трекеры, события, коллбэки.

## 5а. Таблица плана и финотчёт

- Таблица: «План, прогноз и факт — декабрь 2025–декабрь 2026», `https://docs.google.com/spreadsheets/d/1ADr8aO0f29ahNJMJw4MM8HosWw6Ka8XIBjAv7snAS4k/edit?gid=8237089`, лист `Sheet1` (gid 8237089).
- Колонки: на каждый месяц «План | Прогноз | Факт». Октябрь 2026 = V | W | X, ноябрь = Y | Z | AA, декабрь = AB | AC | AD. Перед записью сверь шапку (строки 1–2): колонки могли сдвинуться.
- `A1` — подпись даты факта: «Факт <месяца>: 01–ДД.ММ.ГГГГ».
- Чтение и запись — MCP `google-sheets`: `rows-get` (range, render FORMULA — увидеть формулы), `values-batch-update` (USER_ENTERED). Запас — Comet: `fetch(.../export?format=tsv&gid=8237089)` и ввод через name box.

### Финотчёт → таблица (строки блока «Mashina»)

| Строка финотчёта | Строка таблицы |
|---|---|
| Промо | 5 Промо |
| Бизнес аккаунты | 6 Бизнес-тарифы |
| Публикации | 7 Платные публикации |
| Отчеты | 8 Отчёты по авто |
| Разница CashIn/CashOut | 9 CashIn/CashOut (минус) |
| Кредиты MBANK | 10 Кредиты |
| Лизинг | 11 Лизинг («-» = 0) |
| Страхование | 12 Страхование |
| Mashina (итого) | 4 — формула, не пишешь |

- Пишешь только числа в «Факт» и «Прогноз» строк 5–12 текущего месяца и дату в `A1`.
- Не трогаешь: строку 4 (сумма 10–12 + 13), строку 13 (сумма 5–9), «План» строк 5–7 (формула: план делится по долям факта), остальной «План», строки 15+ (это Redash).
- MHouse, MBazar, спецпроекты, баннерная реклама — не Mashina, в таблицу не вносишь.
- Проверка после записи: строка 4 «Факт» = итог «Mashina / Факт» финотчёта; «Прогноз» — ± 1 сом (округление); «План» строк 5–7 совпал с финотчётом. Не совпало — ищешь ошибку ввода.
- Ввод в Comet (только если MCP не работает): name box (`A1`-поле слева от строки формул) → адрес → Enter → числа через `\n` по столбцу. Текст в `A1` — через F2 + Ctrl+A, иначе первые буквы теряются.

## 6. Работа в Comet

1. `tabs_context_mcp` → новая вкладка `tabs_create_mcp`. Чужие вкладки пользователя не трогаешь.
2. Не нажимаешь кнопки, которые сохраняют, удаляют, делятся или вызывают диалоги.
3. Требуется логин, 2FA или капча — стоп, просишь пользователя войти. Пароли и коды не вводишь.
4. Один `javascript_tool` — до 45 с: 3–4 загрузки за вызов.
5. 2–3 неудачные попытки — стоп, пишешь, что не получилось, и спрашиваешь.
6. В конце закрываешь свои вкладки.
