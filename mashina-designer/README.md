# mashina-designer — агент «Продуктовый дизайнер Mashina.kg»

Агент получает PRD от продакт-менеджера и отдаёт кликабельный HTML-прототип на Design System Mashina.kg: web 1440 и mobile 390, все экраны, окна и состояния, режим «Спека» и журнал событий для разработки.

Это шаг 1 цепочки «ИИ-агенты для фронта» (встреча 15.10.2026): лор → скилл → агент. Прототип и `handoff.md` — вход для агента фронтенда.

## Как запустить

| Где | Как |
|---|---|
| Claude Code, чат с PM | `/mashina-designer <путь к PRD>` или «сделай прототип по PRD …» |
| Claude Code, из другого агента | Агент `mashina-designer` (`~/.claude/agents/mashina-designer.md`) |
| Другая модель (DeepSeek и т. п.) | Системный промпт = `lore.md` + `SKILL.md`; нужны Node.js и playwright для сборки и снимков |

## Состав

| Путь | Что это |
|---|---|
| `SKILL.md` | Порядок работы: PRD → вопросы → карта экранов → исходники → сборка → снимки → handoff |
| `lore.md` | Роль: опыт, рынок КР, продукт, знания на 10.2026, принципы, голос, границы |
| `design-system/` | Токены, компоненты, живой каталог `kit.html`, иконки, логотип — выгрузка из Figma |
| `references/prototype-format.md` | Формат исходника: атрибуты `data-*`, окна, состояния, API |
| `references/review-checklist.md` | Самопроверка перед сдачей |
| `references/company.md`, `site-ui.md` | Компания, рынок, текущий сайт — только открытые данные. Кадры сайта в пакет не входят: они в проекте Mashina.kg, `04_outputs/final/site_research_2026-10-16_ui-for-designer-agent/кадры-для-агента/` |
| `references/ds-update.md` | Как перевыгрузить DS из Figma |
| `templates/` | Стартовые исходники, шапка, подвал, панели, шаблон `handoff.md` |
| `runtime/` | Механика прототипа: экраны, окна, состояния, «Спека», события |
| `scripts/build.cjs` | Сборка исходника в один HTML без внешних файлов и проверка DS |
| `scripts/shoot.cjs` | PNG всех экранов и окон и отчёт об ошибках |

## Данные

В лоре и справочниках только открытые сведения. Внутренние метрики, выручка, Jira и Confluence сюда не попадают: пакет можно отдать другой модели.
