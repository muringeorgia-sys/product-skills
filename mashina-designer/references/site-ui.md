# Mashina.kg: как выглядит текущий сайт (замеры 2026-10-16)

Только публичные страницы mashina.kg, без входа и без отправки форм. Размеры сняты через computed styles в браузере; цвета переведены в HEX. Кадры лежат в проекте Mashina.kg, папка `04_outputs/final/site_research_2026-10-16_ui-for-designer-agent/кадры-для-агента/` (имена `d..` — десктоп 1440, `m..` — мобильное окно 390). В пакет скилла они не входят: решение PO 16.10.2026, чтобы кадры не уходили в GitHub.

## 0. Условия замеров и что они значат

| Параметр | Десктоп | Мобильный веб |
|---|---|---|
| Окно | всплывающее окно Chromium (Edge 155), innerWidth 1440×746, DPR 1,25 | то же, innerWidth 390×746, DPR 1,25 |
| Ширина раскладки | 1425 px: классическая полоса прокрутки 15 px | 375 px по той же причине |
| Пересчёт | контейнер 1200 по центру; без полосы поля по 120 px, с полосой по 112,5 | ширина контента = ширина окна − 32; на телефоне 390 это 358 px (в кадрах 343) |
| Устройство | настоящий десктоп | десктопный user agent, touch 0, screen.width 1536: узкое окно, не телефон и не эмулятор |
| Тема | тёмная (в браузере включена тёмная схема); светлая снята только на главной (кадр OBS-05, есть в папке подтверждений проекта, в пакете его нет), остальное по токенам из CSS | тёмная |

Мобильная раскладка определяется шириной окна: в JS сайта хук `useIsMobile` на `matchMedia("(max-width: 767px)")`, определения мобильного по user agent в 48 просканированных клиентских файлах нет (есть только `isBot`). Поэтому узкое окно близко к тому, что увидит телефон, но SSR для мобильного UA, touch и safe-area не проверены.
Границы 1 px в замерах равны 0,8 px из-за DPR 1,25; значения вида 43,6 px = 44 px номинально.
Цифры ниже — из computed styles, если не сказано «по кадру» или «по классам» (значение взято из имён классов Tailwind, а не из замера).

Mobile 390 (кадры m01, m03): те же блоки без перестройки. Правая группа не помещается: scrollWidth страницы 607 px (главная, выдача) и 626 px (страницы с меню категорий), горизонтальная прокрутка есть. «Для бизнеса» переносится на две строки, логотип и «Создать объявление» уходят за правый край, заголовок «Все машины Кыргызстана здесь» наезжает на плитки. Меню-бургера нет. Нижней панели нет: элементов с `position: fixed` в DOM нет; единственный `position: sticky` на странице объявления — блок продавца (`sticky top-5`), на mobile он стоит в потоке страницы после калькулятора. Панели с кнопками, закреплённой к низу экрана, в окне 390 не обнаружено.

- Реальный телефон, эмулятор, нижняя панель и шапка на настоящем мобильном UA, ширины 768–1023.

- /carcheck, страница дилера /dealers/<имя>, цены тарифов выше уровня Active.
