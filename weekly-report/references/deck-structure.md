## Правила слайдов

- Релизы: прошедший, текущий и ближайшие по версиям Jira. Жирным — только эпики со слайда «Ключевые фичи» (`key_bold`). Причина «не вошло» = статус Jira на дату ухода эпика из версии.
- **Слайд релиза = эпики + задачи без эпика** (решение PO 04.11.2026). Колонки Чиним / Улучшаем / Добавляем (вариант «Баги / Фичи» PO отклонил 04.11). Эпики — цветом стадии, задачи MASH без эпика — в своей колонке без фона, с тегом статуса. Отдельного слайда «ещё N задач без эпика» нет. Колонки задаёт продукт по смыслу; 04.11 PO отнёс к «Чиним» «Отображение официальных дилеров», «Контакты менеджера по продажам на сайте», «Логотип марки ROX». Сборка — `tmp/weekly_2026-11-04/scripts/slides_data.cjs` (блок REL) + `update.ps1`.
- **Задачи без эпика** (решение PO 03.11.2026; с 04.11 — на слайде релиза, не отдельным слайдом). Для каждого релиза на слайдах, кроме эпиков, смотри панель разработки: Jira Cloud, cloudId `d8bb86b3-821b-4ab0-be14-90e1d9acbcdc`, JQL `project = MASH AND parent is EMPTY AND issuetype not in (Epic, subTaskIssueTypes()) AND fixVersion = "Mashina.kg ДД/ММ/ГГГГ"`. Проверка полноты: тот же JQL с `fixVersion is EMPTY AND (sprint in openSprints() OR sprint in closedSprints() AND resolved >= <начало прошлого спринта>)` — найденное назови в ответе PO, на слайд не ставь. Название — по-русски, без префиксов `[mobile][mashina.kg]` и ключей. Тег: Done в выпущенном релизе — «вышло», в будущем — «готово» (зелёным); Ready to test — «готово к тесту»; Review — «код-ревью»; In Progress — «в разработке»; Backlog, To Do — «бэклог». Колонка Чиним / Улучшаем / Добавляем — по смыслу задачи; пустую не выводить. В заметках: JQL, дата статусов, ключи со статусами. Данные — JSON по образцу `tmp/unrel_2026-11-03/unlinked.json`, сборка: `powershell -NoProfile -ExecutionPolicy Bypass -File 03_scripts/stable/unlinked_tasks_slides.ps1 <src> <out> <json> <png>` (копирует слайд релиза, ставит сразу за ним). Номера частей на обложке сдвинь (поле `cover`).
- «Ключевые фичи» — план PO, может расходиться с Jira. Показываешь как дал PO, расхождения — в ответе, Jira не трогаешь.
- Стадии фона (палитра PO 26.10, решение 02.11): без фона — идея («Инициатива», «Исследование», «Бэклог исследования», «Оценка и приоритизация»); белый с рамкой — требования; розовый — QA-анализ; фиолетовый — дизайн; жёлтый — тех. оценка; зелёный — разработка и тесты; «Выпущено» — без фона, статус зелёным. «Исследование» оранжевым не выделять.
- Новая фича в списке — добавить в `FEATURES` и в `METRIC_OF`, иначе скрипт остановится.
- Состав может меняться: PO удаляет и добавляет слайды руками. Номера сверяешь с последним файлом, а не с этой таблицей.
- Имя итога: `S<NN>_<спринт>/Отчёт_Недельный-продуктовый_<пн ГГГГ-ММ-ДД>_<вс ГГГГ-ММ-ДД>.pptx`, без tmp-имён и версий.
