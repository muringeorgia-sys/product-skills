# Как поставить скилл weekly-report

Скилл собирает еженедельный продуктовый отчёт Mashina.kg: выгружает данные из Redash и Google Таблицы задач и собирает презентацию `.pptx` из шести слайдов.

## 1. Куда положить

Claude Code, личные скиллы пользователя:

- Windows: `C:\Users\<имя>\.claude\skills\weekly-report`
- macOS и Linux: `~/.claude/skills/weekly-report`

Распакуйте архив так, чтобы `SKILL.md` лежал прямо в папке `weekly-report`. После этого перезапустите сессию Claude Code — скилл появится в списке и вызывается командой `/weekly-report` или фразой «собери еженедельный отчёт».

Если скилл нужен всей команде в одном репозитории, положите папку в `<проект>/.claude/skills/weekly-report` — тогда он работает только внутри этого проекта.

## 2. Что должно быть на машине

| Нужно | Зачем | Проверка |
|---|---|---|
| Node.js 18+ | сборка презентации | `node --version` |
| Пакеты `pptxgenjs` и `jszip` | генерация `.pptx` и правка XML подсказок | `npm i pptxgenjs jszip` в папке проекта, откуда запускается сборка |
| PowerPoint (Windows) | рендер слайдов в PNG для визуальной проверки | скрипт в SKILL.md, шаг 3 |
| Claude in Chrome | выгрузки из Redash, Jira и Google Таблиц | браузер с активной сессией пользователя |

Если PowerPoint нет, рендер можно сделать через LibreOffice: `soffice --headless --convert-to pdf`, затем `pdftoppm`. Тогда поправьте команду проверки в `SKILL.md`.

## 3. Доступы

- **Redash** `http://92.204.189.31:8082` — пользователь должен быть залогинен в браузере. Скиллы читают запросы 348, 430, 536, 303, 326, 336, 364, 438, 549 и делают SELECT-выборки через `/api/query_results`. Ничего не сохраняет.
- **Jira** `https://jira.mashina.kg` — нужен только для ответа «что сделали» в чате, в презентацию не идёт.
- **Google Таблица «Задачи Mashina.kg»** — читается CSV-выгрузкой листов со спринтами.

Все адреса, идентификаторы запросов и правила описаны в `SKILL.md`. Под другой продукт меняются: список запросов Redash в `scripts/redash_collect.js` и `scripts/redash_extra.js`, ссылка на таблицу задач в `SKILL.md`, реестр отчётов `sources` в JSON презентации.

## 4. Что внутри

```
SKILL.md                                  правила и порядок работы
scripts/redash_collect.js                 основной scorecard из Redash
scripts/redash_extra.js                   доп. метрики и парсер Lalafo
scripts/jira_discovery.js                 доска Product discovery (для чата)
scripts/build_deck.js                     сборка .pptx из JSON
references/deck-data-example.json         пример данных презентации за 07–13.09.2026
references/deck-reference-2026-09-15.pptx эталонный вид презентации
references/ceo-priorities.json            задачи, отмеченные CEO: красятся зелёным
```

## 5. Быстрая проверка

Из папки, где установлены `pptxgenjs` и `jszip`:

```bash
node <путь к скиллу>/scripts/build_deck.js <путь к скиллу>/references/deck-data-example.json test.pptx
```

Должно получиться `saved test.pptx slides 6` и строка про приоритеты CEO. Откройте файл — это тот же отчёт за 7–13 сентября 2026, что и эталон в `references`.

## 6. Как пользоваться

Скажите Claude «собери еженедельный отчёт». Дальше он сам: определит прошлую полную неделю, выгрузит данные, посчитает изменения, соберёт презентацию, отрендерит слайды и проверит их, а результат положит в папку месяца.

Правки к отчёту вносите через JSON с данными, а не в PowerPoint: это дёшево и повторяемо. Если презентацию поправили вручную и такой вид нужен всегда — отдайте файл Claude, он обновит эталон и правила в `SKILL.md`.
