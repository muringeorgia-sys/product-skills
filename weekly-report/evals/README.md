# Проверка презентации weekly-report

`check_deck.mjs` проверяет готовый .pptx по текстовым правилам `references/review-checklist.md`: число слайдов, WAU, «нет данных», строка «Источник», одна дата «данные на», заметки у слайдов. «Доля платящих» и ключи Jira — «ПРОВЕРИТЬ»: в принятом WBR 08.11 они есть (MPAU / MAU на слайде 6, ключи эпиков на слайде 14).

```powershell
node ~/.claude/skills/weekly-report/evals/check_deck.mjs <deck.pptx>
```

Когда:
- шаг «Проверка» недельного отчёта — до PNG-просмотра;
- после правки скилла — на последнем принятом WBR: ошибок быть не должно.

Калибровка 17.11.2026: `S08_22.10-11.11/Продуктовый_WBR_Mashina_2026-11-08_v5.pptx` — 0 ошибок, 2 «ПРОВЕРИТЬ».
Смысловые пункты (цифры против финотчёта, Jira, проверка числа) проверяет агент.
