# Задача, Impact, RICE и сом в месяц

## 1. Метрика плана → бизнес-задача

| Что нужно вырастить | Задача по таблице Замесина |
|---|---|
| Больше платящих среди тех, кто уже размещает (MPAU) | Конверсия |
| Выше чек платящего (ARPPU) | Средний чек |
| Повторные покупки промо, продления тарифа | Возвращаемость |
| Вернуть или удержать платящих продавцов и дилеров | Снизить отток |
| Больше новых продавцов, объявлений, заявок | Привлечь клиентов |
| Новая категория выручки или новый сегмент | Масштабировать |
| Уйти от сравнения с другими площадками по цене | Выйти из прямой конкуренции |
| Чтобы сегмент выбирал Mashina за работу | Вырастить ценность |

Одна цель может дать две задачи. Пример: «добрать Промо» = конверсия (больше покупателей) + средний чек.

По `S08_22.10-11.11/Методика_Выручка-по-фичам-роадмапа_2026-10-23.md`. Базовые цифры — там же, раздел 2, и в `04_outputs/final/po-dashboard/data.json`.

| Категория | Из чего складывается |
|---|---|
| Промо | Покупатели промо × чек × частота покупок |
| Бизнес-аккаунты | Дилеры с тарифом × цена тарифа |
| Публикации | Платные публикации × цена |
| Отчёты | Покупки отчётов × цена − себестоимость |
| Кредиты MBANK | Заявки × доля выданных × сумма × комиссия |
| Лизинг, страхование | Только финотчёт; лиды — Redash 65 |

Рост категории всегда идёт через один множитель — его и называй в гипотезе.

## 3. Impact 1–10 под задачу

Таблица Замесина. 1 — текущее значение, кроме Go To Market и «что не надо делать».

| Задача | 10 = |
|---|---|
| Конверсия | Максимально достижимая конверсия |
| Средний чек | Максимально возможный чек |
| Возвращаемость | Максимально возможная возвращаемость на N-й день, неделю или месяц |
| Снизить отток | Максимально достижимое снижение оттока |
| Привлечь клиентов, канал | Максимальный охват коммуникации |
| Масштабировать | Максимально возможный рост рынка |
| Вырастить ценность | Клиенты однозначно выбирают нас за эту работу |
| Выйти из прямой конкуренции | Нет конкуренции с сильными игроками, сегмент остаётся привлекательным |
| Go To Market | Максимальная инвестиционная привлекательность сегмента; 1 — нет логики выбора |
| Что не надо делать | «Ни в коем случае, точно потеряем деньги»; 1 — нет логики |

**Для метрик нужна гипотеза числа «10».** Без неё шкала не работает. Запиши её в шапке таблицы RICE: «10 = конверсия X% (основание …)». Нет основания — «10» = закрыть разрыв до плана категории, с пометкой «допущение».

## 4. RICE

RICE = R × I × C / E.

| Буква | Что | Как оценить |
|---|---|---|
| R — Reach | Сколько клиентов сегмента затронет за месяц | Число или доля сегмента. Одна единица на всю таблицу |
| I — Impact | Вклад в метрику задачи | 1–10 по разделу 3 |
| C — Confidence | Насколько доказано | По уровню доказанности ниже |
| E — Effort | Сколько работы | Недели команды Mashina: дизайн, разработка, QA. Нет оценки — «оценка PO» и пометка |

Уровни доказанности — как в базе NMT, по канону. Доли — условность скилла для расчёта, не из канона.

| Доказанность | C |
|---|---|
| Мнение | 0,2 |
| Аналитика | 0,4 |
| Опрос | 0,5 |
| Интервью | 0,6 |
| MVP | 0,8 |
| Продажи | 1,0 |

Фильтры после RICE (канон, шаг 7):
- **Юнит-экономика.** Может ли гипотеза в принципе дать целевую маржу на платящего? Нет — убрать.
- **Opportunity cost.** Что не делаем, выбирая топ. Одна строка.

## 5. Сом в месяц для топа

По методике S08, коротко:

| Тип | Формула в месяц |
|---|---|
| A — новая услуга | Клиенты × конверсия × чек × маржа |
| B — рост категории | Выручка категории × Δ% |
| C — через воронку | Δ объявлений, заявок или контактов × деньги на единицу |
| D — без прямой выручки | 0, эффект — через зависимые фичи |

- База — факт, не план. План — только для сравнения итога.
- Сдвиг без данных — три сценария (мин / база / макс) и пометка «допущение».
- Разгон после релиза: месяц 1 — 50%, месяц 2 — 80%, дальше 100% (допущение методики).
- Оплата бонусами — не выручка. У партнёрских сервисов считаем комиссию Mashina, не оборот партнёра.
