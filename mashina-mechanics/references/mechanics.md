## 3. Механики канона сверх таблицы

Привязки к задачам у автора нет — выбирать экспертно.

| Механика канона | Когда смотреть |
|---|---|
| Сократить паузы между работами | Конверсия, возвращаемость: долгое ожидание между шагами |
| Связать Core Job с новой Big Job | Ценность, средний чек |
| Экосистема: продукты 1 + 1 > 2 | Отток |
| Убрать негативные эмоции | Ценность, конверсия: тревога, сомнение, страх ошибки |
| Меньше передач между ролями | B2B, длинная цепь из нескольких людей |
| Починить невыполненные работы в цепи, даже вне Core Jobs | Масштабирование в новый подсегмент |
| Сделать работу за клиента | Средний чек: сегмент «сделайте за меня» |
| Работы ориентации: понять, выбрать, разобраться | Привлечение, конверсия новичков |
| Дать ценность по частям раньше | Конверсия: лид-магнит, первая проверка бесплатно |
| Small Jobs, которые появились по ходу | Ценность, средний чек: внезапные задачи на пути |
| Пакет продуктов | Средний чек |
| Убрать циклы «вернуть на доработку» | Конверсия, удержание |
| Починить разрывы цепи между людьми | B2B, сделки с несколькими участниками |

## 4. Из конспектов — проверять

Источник — чужие конспекты курса [К], `NMT-Дополнения/README.md` 2.7. Числа и пороги не переносить без проверки.

- Вернуть работу, которую клиент перестал выполнять.
- Сегмент, готовый платить в 10 раз больше.
- В B2B приоритет — сегментам с коротким циклом сделки.
- Антимеханика: не брать работу, которую крупный игрок включит у всей своей базы.
- Price Sensitivity Meter — 4 вопроса о цене.
