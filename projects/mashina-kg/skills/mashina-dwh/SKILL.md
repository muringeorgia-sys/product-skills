# Mashina DWH (ClickHouse)

Read-only доступ к витринам B2B-аналитики. Три продукта: **RV**, **структура по классам**, **тренды рынка**.

## 1. Подключение

| Шаг | Что делать |
|---|---|
| Инструменты | MCP `clickhouse`: `run_query`, `list_tables`, `list_databases` (загрузить через ToolSearch «clickhouse») |
| Условие | VPN + SSH-туннель на локальный 18123 — запускает пользователь сам |
| Не отвечает | Попросить включить VPN и туннель. Не искать пароли, не читать `~/.claude.json`, не менять конфиг |
| Права | readonly. Только SELECT / DESCRIBE / EXPLAIN. Сервер, dbt, Airflow меняет инженер |

Первый запрос сессии — проверка свежести:

```sql
SELECT max(latest_listing_snapshot_at), max(calculated_at) FROM marts.mart_residual_value_rolling
```

## 2. Какую таблицу брать

| Вопрос | Таблица | Обязательный фильтр |
|---|---|---|
| RV на 12/24/36 мес | `marts.mart_residual_value_rolling` | `requested_window_months` |
| RV по календарным годам | `marts.mart_residual_value_calendar` | `report_start`; текущий год — `is_partial_period=1` |
| Структура по классам | `marts.mart_market_segmentation` | `period_type`, `period_start`, **`location_scope='all'`** |
| Объём, лидеры, динамика | `marts.mart_market_trends` | **`summary_level`** = market / class / model |
| Разбор конкретных машин, аудит | `staging.int_vehicle_period_prices` | `period_type` (month / year) |
| Объявления, статусы, город | `staging.int_vehicle_listings` | ключ `source_record_key` |

`marts.mart_residual_value` — старый прототип с другой методикой. Не смешивать с calendar / rolling.

Поля и значения — [references/schema.md](references/schema.md). Готовые запросы — [references/queries.md](references/queries.md).

## 3. Правила, которые нельзя нарушать

1. **С 12.11.2026 порогов нет: n ≥ 1** (решение PO). Метки `very_thin` / `directional` / `sufficient_sample` — только описание, не фильтр. n показывать рядом с ценой.
2. RV в длинном формате: строка = когорта (модель, поколение, силовая установка, год выпуска) × год наблюдения. Все возрасты. RV = цена б/у ÷ **историческая** цена новой той же когорты. Старых полей `rv_age_N_pct`, `report_eligible_all_ages` нет.
3. RV > 100% → `review_ratio_above_100`, **процент показывать** с пометкой. Не фильтровать по `rv_status = 'eligible'` — пропадут строки > 100% и строки только с ценой.
4. Не складывать: `Всего` с классами; разные `location_scope`; разные `summary_level`; month с year.
5. Медиану не собирать из медиан классов — брать строку `Всего`.
6. Электро = класс `электро`. Гибрид — класс по размеру + флаг powertrain.
7. Текущий год (2026) неполный. Сравнивать только полные годы или равные периоды.
8. Продажи, активный сток, срок экспозиции, доля дилеров — **не рассчитаны** (null ≠ 0). Не заполнять допущениями.
9. Конфликт классов RV (`conflicting_assigned_classes`) не решать по большинству, максимуму или порядку. Нужен проверенный маппинг модели → решение продукта.
10. Цифры из скриншотов клиента — случайные. Не использовать.

## 4. Как называть цифры

| В данных | Говорить | Не говорить |
|---|---|---|
| `vehicles_published` | машины в объявлениях Mashina (оценка) | продажи, парк страны |
| `median_asking_price_usd` | медиана цены в объявлении | цена сделки |
| `rv_pct` | цена б/у когорты к исторической цене новой той же когорты | потеря стоимости одной машины |
| `listed_model_rank_in_class` | лидер по числу объявлений | лидер продаж |
| `vehicle_key` | оценка машины в пределах продавца | уникальный автомобиль |

Возраст = год публикации − год выпуска. Цена — последний снимок объявления, не история правок.

## 5. Порядок работы

1. Проверить свежесть (п. 1). Записать дату снимка в результат.
2. Выбрать таблицу (п. 2). Не уверен в поле — `DESCRIBE TABLE`.
3. Тяжёлый запрос к staging (3,5–6,5 млн строк) — сначала `EXPLAIN ESTIMATE`, всегда `LIMIT` при выгрузке строк.
4. Проверить итог: сумма классов (без `Всего`) = `Всего`; число строк выгрузки = витрина.
5. Результат — md в папке задачи: таблица, n рядом с каждой медианой, окно, дата снимка, ограничения.
6. Новые факты о данных (изменилась схема, порог, число конфликтов) — дописать в [references/schema.md](references/schema.md) с датой.

## 6. Чего не делать

- Не просить и не показывать пароли, ключи, SSH-конфиг, env.
- Не предлагать перезапуск контейнеров, апгрейды, открытие портов.
- Не возвращаться к закрытым темам (курсы валют, сверка объявлений, группировка) без нового конкретного бага.
- Не делать вывод «почему у модели два класса» по массиву классов — только по разбору записей в `int_vehicle_period_prices`.
