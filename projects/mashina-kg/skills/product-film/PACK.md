# Переносимая копия

Инструкция и прикладные ресурсы сохранены с лицензиями. Личные настройки и доступы автора отсутствуют. Сначала проверь доступные программы и инструменты своей среды. Ссылки на browser и browser-harness означают уже настроенный у тебя браузерный инструмент; не ищи личный браузер автора.

Внешние действия подчиняются правилам твоего проекта. В режиме знакомства подготовь файлы локально, без публикации и отправки. Доставка на Mac автора не применяется: верни результат владельцу текущего проекта в согласованное место.

Музыкальные файлы и звуковые эффекты из общей библиотеки исключены: в её README права не подтверждены. Видеопримеры архива идут без звука. Для музыки возьми свой разрешённый трек или синтезатор product-film/scripts/synth-score.py. Не пытайся скачать исключённые аудиофайлы автоматически.

product-film содержит сценарий, шаблоны и скрипты Remotion; зависимости устанавливаются штатным способом при создании твоего видео. brag содержит часть native Hyperframes plugin, необходимую этому сценарию, в vendor/hyperframes; его launcher фиксирует версию и не устанавливает глобальные навыки. brag-slim может сделать ролик доступными инструментами без полного движка.
