# Метки Jira Mashina.kg

Справочник утверждён PO 13.10.2026. Метки чувствительны к регистру и не содержат пробелов. Новая метка — только после «да» PO и дописывания сюда.

## 1. Категории выручки

Главные метки: по ним PO смотрит план по выручке категорий. Эпик получает категорию, если фича прямо меняет деньги в этой линии. Категорий может быть несколько.

| Метка | Когда ставить | Пример |
|---|---|---|
| `Промо` | Продвижение объявлений: Exclusive, VIP, TOP, UP, «Срочно», промопакеты, бонусы на продвижение | PRODUCT-314 Значки услуг продвижения |
| `Тарифы` | Тарифы дилеров и бизнес-аккаунтов, подписки | PRODUCT-331 Отключение функций бизнес-тарифа |
| `Публикации` | Платная подача, срок размещения, продление | PRODUCT-306 Срок размещения и продление |
| `Отчёты` | Отчёты по VIN и госномеру, их покупка и пакеты | PRODUCT-298 Проверка авто по VIN |
| `Кредиты` | Автофинансирование MBANK, кредитный потенциал, калькулятор | PRODUCT-300 Кредитный потенциал |
| `Лизинг` | Заявки и маршрутизация лизинга, отчётность по лизингу | PRODUCT-442 Правила распределения авто |
| `Страхование` | ОСАГО, КАСКО, кэшбэк страхования | PRODUCT-401 Лейбл «22% кэшбек» |
| `Пополнения` | Пополнение баланса, платёжный поток | PRODUCT-322 Пополнение баланса |

Решения PO, которые повторять:
- Отчётность по лизинговым заявкам — `Лизинг`, не `Отчёты`.
- Общий платёжный поток (быстрая оплата, бонусы) — все категории, которые он затрагивает, по разделу требований.
- Старое имя `Кредиты_MBANK` не использовать.

## 3. Командные и служебные метки

| Метка | Смысл | Правило |
|---|---|---|
| `Fintech` | Эпик финтех-команды (Рахат) | Только латиницей с большой буквы. Новый эпик с ней назначается на Рахата (правило 46). Не путать с категорией: лизинг-эпик = `Fintech` + `Лизинг` |
| `тех-оценка` | Служебная, ставилась правилами 25–27 на задачи MASH | Не трогать, не ставить руками |
| `дубль` | Дубликат задачи | Ставить по согласованию PO; в MASH не ставить |
| `Mashina.kg`, `House.kg`, `Bazar.kg` | Продукт в проекте MASH | Только MASH; в остальных проектах продукт = поле 10201 |

## 4. Охват

| Что | JQL | Правило |
|---|---|---|
| Эпики Mashina.kg | `project = 10001 AND issuetype = 10000 AND cf[10201] = "Mashina.kg"` | У каждого ≥ 1 метка из разделов 1–2 |
| Эпики House.kg и Bazar.kg | `project = 10001 AND issuetype = 10000 AND cf[10201] in ("House.kg","Bazar.kg")` | Справочник для них не утверждён — только отчёт, без записи, вопрос PO |
| Задачи MASH, QA, DESIGN | — | Метки категорий не ставим, если PO не попросит |

Включая выпущенные и отменённые эпики, если PO не сказал иначе.

## 5. Как писать

- Перечитать текущие метки → `PUT /rest/api/2/issue/<key>` с `{"update":{"labels":[{"add":"Промо"}]}}`.
- Удаление — только по «да»: `{"remove":"..."}`.
- После записи — повторная выборка и протокол в `tmp/scrum-master/YYYY-MM-DD/`.
