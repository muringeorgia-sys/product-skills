# Дизайнер отчётных презентаций Mashina.kg

Сначала `lore.md`, затем этот файл, затем `references/deck-structure.md` и `references/inputs.md`.

Проект: `C:\Users\ueabq\OneDrive\Документы\ChatGPT\Mashina.kg` (дальше `<проект>`).

## Справочники

| Файл | Когда открывать |
|---|---|
| `references/deck-structure.md` | Всегда: состав слайдов, чем собирается каждый |
| `references/inputs.md` | Всегда: где входы, что нужно от аналитика и скрам-мастера |
| `references/design-system.md` | Шаг 4–5: цвета, стадии, плотность |
| `references/review-checklist.md` | Шаг 6: проверка перед сдачей |
| `~/.claude/skills/weekly-report/SKILL.md` | Только нужный раздел: правила метрик, подсказок, релизов, сбои сборки |
| `<проект>/_БАЗА/Источники-и-правила-продуктового-отчёта.md` | Правила выручки, планов, отображения месяцев |
| `<проект>/03_scripts/stable/README.md` | Запуск скриптов сборки |

## Режимы

| Режим | Запрос | Результат |
|---|---|---|
| Новый отчёт | «собери отчёт / презентацию за неделю» | Новый файл недели в папке спринта |
| Правка | «обнови слайд N», «поправь заголовок», «добавь строку» | Тот же файл, изменены только названные слайды |
| Проверка | «проверь презентацию» | Список нарушений по `review-checklist.md`, без правок |

## Порядок работы

1. **Период и основа.** Отчётная неделя — прошлые пн–вс, если PO не назвал иначе. Основа — самый новый `Отчёт_Недельный-продуктовый_*.pptx` в папках `S*`. Прочитай порядок и заголовки его слайдов (распаковка pptx, тексты `a:t`), сверь с `deck-structure.md`: PO мог удалить или переставить слайды.
2. **Входы.** Найди свежие отчёты аналитика и скрам-мастера по `inputs.md`. Чего нет или устарело:
   - работаешь с PO — один вопрос AskUserQuestion: «Запустить аналитика и скрам-мастера» (рекомендуется) / «Собрать по тому, что есть» / «Остановиться»;
   - вызван агентом — собираешь из того, что есть, и возвращаешь готовые запросы из `inputs.md`.
3. **Карта изменений.** Таблица «слайд → что меняется → вход». Неизменившиеся слайды не трогаешь. Сверь итог выручки с финотчётом; расхождение — найди причину во входе аналитика.
4. **Данные слайдов.**
   - Блок «Данные» в `build_monthly_wbr_slides.cjs`: выручка, метрики, `FEATURES`, `METRIC_OF`, перцентили, ключевые фичи. Перед правкой — копия скрипта в `tmp/report-designer/<дата>/`.
   - JSON для `build_monthly_report.cjs`: таблицы, релизы, слайды ключевых фич. Основа — прошлый JSON из `tmp/weekly_*/`; обнови период, значения, статусы, `tip`, `notes`.
   - Заголовки — выводы с цифрой. Формулируешь по входу аналитика, не выдумываешь причины.
   - Заметки слайда: источники, расчёты, ключи Jira, переезды эпиков, допущения.
5. **Сборка.** Рабочая папка — `<проект>/tmp/report-designer/<ГГГГ-ММ-ДД>/` (внутри проекта: PowerPoint не открывает файлы из системного Temp).
   - `node 03_scripts/stable/build_monthly_wbr_slides.cjs <tmp>/wbr.pptx`
   - `node 03_scripts/stable/build_monthly_report.cjs <deck.json> <tmp>/mini.pptx`
   - Копия основы → `<tmp>/base_backup.pptx`.
   - `powershell -NoProfile -ExecutionPolicy Bypass -File 03_scripts/stable/replace_slides.ps1 <основа> <итог> <tmp>/png "<map>"` — пути абсолютные, map вида `2=<wbr>#1;5=<wbr>#2`.
   - Новый слайд — PowerPoint `InsertFromFile` в нужную позицию. Обложку правишь текстом в копии.
   - Обложка и период: «<д>–<д> <месяц> 2026 · данные на ДД.ММ».
6. **Проверка.** Экспортируй PNG всех изменённых слайдов (их отдаёт `replace_slides.ps1`), открой каждый и пройди `review-checklist.md`. Нарушение — исправь и пересобери.
7. **Сдача.** Итог — `S<NN>_<спринт>/Отчёт_Недельный-продуктовый_<начало>_<конец>.pptx`. Новый файл — строка в `_ВИКИ/index.md` и запись в `_ВИКИ/log.md` по формату соседних строк.
8. **Ответ.** Ссылка на pptx и 1–2 строки. Отдельным коротким списком — только то, что PO должен знать: пробелы данных, расхождения с финотчётом, ключевые фичи без версии в Jira. Если вызван агентом — формат из файла агента.

## Сбои

- `EBUSY` при сборке — файл открыт в PowerPoint. Попроси PO закрыть, пока собирай во временный файл в `tmp/` проекта.
- `нет фичи в FEATURES` — добавь фичу в `FEATURES` и `METRIC_OF`.
- PowerPoint COM не отвечает — закрой процессы `POWERPNT`, которые запустил сам, повтори один раз. Не помогло — блокер, скажи PO.
- Вход противоречит прошлому отчёту без объяснения — не выбирай сам, верни вопрос аналитику.
