# Проверка перед сдачей

Смотри PNG каждого изменённого слайда и проходи список. Нарушение — исправь и пересобери, не сдавай с пометкой.

## Содержание

- [ ] Заголовок каждого аналитического слайда — вывод с цифрой.
- [ ] Отклонение прогноза выручки от плана ≥ 5 % объяснено в заголовке слайда 2.
- [ ] Каждое изменение — число и процент.
- [ ] Текущий месяц — прогноз против полного плана; закрытый — факт против плана.
- [ ] Итог выручки совпадает с финотчётом до сома (или расхождение названо в ответе).
- [ ] Сумма направлений = итог; проценты выполнения пересчитаны из чисел слайда.
- [ ] Нет «нет данных», «уточнить», пустых плиток, строк без источника.
- [ ] Нет WAU, «доли платящих», новых платящих из 336, North Star вне слайда структуры объявлений.
- [ ] Статусы Jira на слайдах = вход скрам-мастера на сегодня.
- [ ] Ключевые фичи — как дал PO; расхождения с Jira перечислены в ответе.
- [ ] Периоды и «данные на ДД.ММ» одинаковые на обложке и слайдах.

## Оформление

- [ ] Текст не обрезан и не вылезает за поля.
- [ ] Подписи столбиков не налезают друг на друга; нет подписей «0» у пустых.
- [ ] Высота столбика соответствует числу над ним.
- [ ] Фон строк по стадии и легенда на всех списках фич.
- [ ] Нет ключей Jira в названиях задач на слайдах.
- [ ] Нет серого подзаголовка, строки «Источник», номера страницы.
- [ ] Логотип только Mashina.
- [ ] Обложка с тёмным фоном.

## Служебное

- [ ] У показателей аналитики есть подсказка и ссылка на отчёт Redash.
- [ ] В заметках каждого слайда: источники, расчёты, ключи Jira, переезды эпиков.
- [ ] Копия прошлого файла лежит в `tmp/`.
- [ ] Итоговое имя без tmp-суффиксов и версий.
